# 🎺 Sistema de Controle da Fanfarra

Todos os arquivos principais ficam na mesma pasta:

- index.html
- alunos.html
- instrumentos.html
- style.css
- app.js

A versão funciona no GitHub Pages e salva os dados no navegador usando localStorage.

## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os cinco arquivos para a raiz do repositório.
3. Vá em Settings > Pages.
4. Escolha Deploy from a branch.
5. Selecione a branch main e a pasta / (root).
6. Salve.
